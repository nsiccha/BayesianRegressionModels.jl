Model syntax ​

Build a regression with several predictors, shared group effects and reusable components from one @brm declaration. The examples use named tuples; a data frame works too. Columns may have different lengths when they describe different observation or group axes.

Formulas and links ​

This model predicts both the mean and the standard deviation. The subject's intercept and slope are correlated, and the scale stays positive through its explicit log link.

brm-comparison
Mean and scale regression
julia
using BayesianRegressionModels

builder = @brm begin
    mu ~ 1 + x + (1 + x | person | subject)
    log(sigma) ~ 1 + x
    y ~ Normal(mu, sigma)

    effect(mu, :) ~ Normal(0, 1)
    effect(sigma, Intercept) ~ Normal(-1, 0.5)
    effect(sigma, x) ~ Normal(0, 0.2)
    sd(:, person) ~ Exponential(0.5)
    cor(:, person) ~ LKJCholesky(2, 2)
end
data = (; subject=["a", "a", "b", "b", "c", "c"],
          x=[-1., 1., -1., 1., -1., 1.],
          y=[-0.6, 0.9, -0.2, 1.4, -0.8, 0.5])
model = builder(data)

transformed data {
    matrix[x_n, 2] X_mu = hcat(rep_vector(1.0, num_elements(x)), x);
    int pop_mu_n_covariates = 2;
    matrix[x_n, 2] Z_mu_person_subject = hcat(rep_vector(1.0, num_elements(x)), x);
    matrix[x_n, 2] X_log_sigma = hcat(rep_vector(1.0, num_elements(x)), x);
    int pop_log_sigma_n_covariates = 2;
}
parameters {
    cholesky_factor_corr[n_terms_person_subject] b_person_subject_L;
    vector<lower=0.0>[n_terms_person_subject] b_person_subject_tau;
    vector[(n_terms_person_subject * n_subject)] b_person_subject_z_flat;
    vector[pop_mu_n_covariates] pop_mu_beta_pop;
    vector[pop_log_sigma_n_covariates] pop_log_sigma_beta_pop;
}
transformed parameters {
    matrix[n_terms_person_subject, n_subject] b_person_subject_z = to_matrix(b_person_subject_z_flat, n_terms_person_subject, n_subject);
    matrix[n_subject, n_terms_person_subject] b_person_subject = ((diag_pre_multiply(b_person_subject_tau, b_person_subject_L) * b_person_subject_z)');
    vector[x_n] pop_mu = (X_mu * pop_mu_beta_pop);
    vector[subject_idx_n] r_mu_person_subject = rows_dot_product(Z_mu_person_subject, b_person_subject[subject_idx, col_idx_mu_person_subject]);
    vector[x_n] mu = (pop_mu + r_mu_person_subject);
    vector[x_n] pop_log_sigma = (X_log_sigma * pop_log_sigma_beta_pop);
    vector[x_n] log_sigma = pop_log_sigma;
    vector[x_n] sigma = exp(log_sigma);
}
model {
    b_person_subject_L ~ lkj_corr_cholesky(b_person_subject_lkj_eta);
    b_person_subject_tau ~ exponential((1.0 ./ 0.5));
    b_person_subject_z_flat ~ std_normal();
    pop_mu_beta_pop ~ normal([0, 0]', [1, 1]');
    pop_log_sigma_beta_pop ~ normal([-1, 0]', [0.5, 0.2]');
    y ~ normal(mu, sigma);
}
generated quantities {
    vector[y_n] y_likelihood = normal_lpdfs(y, mu, sigma);
    vector[y_n] y_gen = normal_vector_rng(y_n, mu, sigma);
}

~ introduces a formula or a probability law; = computes a value. A formula allocates coefficients for its terms. Write 1 for an intercept: BRM does not insert one. The name sigma above holds the response-scale value exp(linear predictor). Its prior address is effect(sigma, ...); applying exp to sigma again would apply the link twice.

The BRM, intermediate-representation, StanBlocks and Stan panes all come from the same bound model. The following inspection checks the authored inputs and keeps the prior declarations visible.

Familiar formulaBRM meaning
1 + x + zAn intercept and two population effects
x * z / x & zMain effects plus interaction / interaction alone
(1 + x | subject)Correlated subject intercepts and slopes
(1 + x || subject)Independent subject intercepts and slopes
(1 | p | subject) in two predictorsOne correlation block spanning both predictors
(1 | gr(subject; by=arm))Separate group-effect distributions by stratum
Two response statementsA joint model; shared names share parameters
y ~ Normal(@brm(1 + x), exp(@brm(1)))Nested mean and log-scale formulas

Integer, string and categorical columns are factors; use floating-point values for a numeric trend. With an intercept, factors use treatment contrasts. Without one, the first eligible factor uses one coefficient per level. factor(g; cmc=false) keeps treatment coding; factor(g; ref=k) chooses a reference level. The reference gives the interaction and ordinal exceptions.

Nonlinear models and plates ​

Ordinary assignments combine sampled values without adding coefficients. This exponential-decay model has one rate per unit and several observations per unit. A groups binding connects the two axes.

brm-comparison
Two axes connected by a plate
julia
decay = @brm begin
    log(rate) ~ 1 + (1 | unit)
    rows = groups(observation_unit => unit)
    @plate for i in eachindex(rate)
        mean_y = amplitude * exp.(-rate[i] .* time[rows[i]])
        y[rows[i]] ~ Normal(mean_y, noise)
    end

    amplitude ~ LogNormal(0, 0.5)
    noise ~ Exponential(0.2)
    effect(rate, Intercept) ~ Normal(-1, 0.5)
    sd(rate, unit) ~ Exponential(0.3)
end

The loop follows the unit-level rate vector. Inside the cell, rate[i] is a unit's value, time[rows[i]] its observations, and bare amplitude is shared. Cell code uses Julia broadcasting explicitly. A bare left-hand name is local; an indexed left-hand name exposes a model output. Observe the response slice directly: an assignment that aliases it does not become a new observation.

For long-format series, @plate for p in groups(unit; order=time) iterates each unit's ordered row indices. An @scan within the cell states a recurrence; AR1Normal(mu[p], sigma, phi; time=time[p]) supplies an AR(1) residual law that accounts for gaps. Response families distinguishes residual dependence from a latent rw, dar or cdar term.

Reusable components ​

A function-style component gives each call its own parameters. Shared values are explicit arguments. This calibration is used twice with separate local intercepts and slopes.

brm-comparison
Independent calls with a shared prior scale
julia
"A calibration curve; every call owns its intercept and slope."
@brm function calibration(x, shared_scale)
    value = a + b * x
    a ~ Normal(0, shared_scale)
    b ~ Normal(1, 0.2)
    return value
end

joint = @brm begin
    left ~ calibration(x_left, shared_scale)
    right ~ calibration(x_right, shared_scale)
    y_left ~ Normal(left, noise)
    y_right ~ Normal(right, noise)
    shared_scale ~ Exponential(1)
    noise ~ Exponential(0.5)
end
model = joint((; x_left=[-0.4, 0.2, 0.7], x_right=[0.3, -0.2],
    y_left=[0.1, 0.4, 0.8], y_right=[0.3, -0.1]))

(:left,)(:right,)

Components accept positional and keyword inputs, including defaults, and resolve functions in their defining module. A named return such as return (; recovery, decay) exposes kin.recovery and kin.decay after kin ~ kinetics(...). Before indexing a returned field in a plate, bind it at model scope, recovery = kin.recovery, then read recovery[i]. brm_components discovers the definitions and call paths; descriptor queries use submodel=:left rather than generated names.

Use merge(structure_a, structure_b, priors_a, priors_b) for fragments that share one namespace. Put structure first and priors last within each scope; moving a cell-local prior outside the plate changes the model. A retained builder can bind new data; reprocess(backend, new_data) instead preserves the fit's preprocessing. These are different operations.

The Warfarin example combines group predictors, nonlinear time courses and observations on several axes.
