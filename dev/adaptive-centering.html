Adaptive centering ​

Adapt the coordinates of hierarchical Gaussian effects during warmup while preserving the model's posterior. Different groups, margins and HSGP frequencies can benefit from different amounts of centering.

Coordinates and the posterior ​

A noncentered scalar effect is b = tau*z, with z ~ Normal(0,1). A centered effect samples b ~ Normal(0,tau) directly. Partial centering uses u = tau^c*z, so b = tau^(1-c)*u. The endpoints c=0 and c=1 are NCP and CP. A coordinate change includes its Jacobian; it does not change the prior or add information.

julia
using Distributions
tau, z = 0.3, 1.2
controls = [0., 0.5, 1.]
logdensities = [logpdf(Normal(0, tau^c), tau^c*z) + c*log(tau) for c in controls]
@assert all(v -> isapprox(v, logpdf(Normal(), z)), logdensities)
collect(zip(controls, logdensities))

(0.0, -1.6389385332046729)(0.5, -1.6389385332046729)(1.0, -1.6389385332046729)

Weakly informed groups often suit NCP, while dense measurements can favor CP. Correlation, uncertain scales and unequal group sizes make a single choice less useful. For correlated blocks the partial coordinates use conditional means and scales in a defined ordering, not independent rescaling of each marginal.

An ordinary hierarchy ​

Eight schools has eight estimated effects, one population location and one between-school scale. The known measurement SDs differ across schools.

    vector[y_n] y_gen = normal_vector_rng(y_n, theta, sigma);

SBBRMI defaults to conventional noncentered random effects. centered_groups=(:school,) chooses a fixed centered Stan representation. RK emits noncentered effects; its adaptive wrapper changes the sampler's frame at runtime. Exact-total and S2Z coordinates are separate preparation choices described in the terms reference.

The fitting workflow ​

For Stan, prepare SBBRMI(model; total_groups=()), instantiate its density with stan_instantiate, then call adaptive_centering_problem(sb, problem, ad_backend). For RK, prepare RKBRMI(model) and rk_logdensity_problem(rk; ad_backend), then pass rk, that problem and the same backend to adaptive_centering_problem. WarmupHMC samples the wrapped problem. Its completion-based workflow runs independent chains; a fit receipt must report any omitted chains.

Inspect adaptive_centering_blocks and adaptive_centering_controls to relate controls to model quantities. The wrapper exposes a grid from zero to one per supported cell. A position loss measures scale variation in candidate frames; a gradient loss measures position–gradient dependence. A pilot-based choice requires a fresh fit, while online adaptation updates during warmup. Compare their full gradient costs, including pilots.

Returned posterior_position draws are in the original model frame. Checkpoint positions may be in the sampler's adapted frame. Keep their frame and control metadata when resuming or auditing a fit; do not feed checkpoint coordinates directly into ordinary prediction.

HSGP frequencies ​

The same idea applies to HSGP weights: each basis function has a spectral scale determined by its frequency and the GP hyperparameters. Low and high frequencies need not select the same centering.

brm-comparison
One control per HSGP weight
julia
model = (@brm begin
    mu ~ 1 + hsgp(time; k=8, domain=(-1.5, 1.5))
    y ~ Normal(mu, sigma)

    effect(mu, Intercept) ~ Normal(0, 1)
    sd(mu, hsgp(time)) ~ Exponential(1)
    sigma ~ Exponential(0.3)
end)((; time=collect(range(-1, 1; length=9)),
    y=[-0.4, -0.5, -0.1, 0.2, 0.6, 0.8, 0.5, 0.2, 0.1]))

functions {
matrix hcat(vector x) {
    int n = dims(x)[1];
    return to_matrix(x, n, 1);
}
vector brm_hsgp_sqrt_spd(
    matrix omega2,
    real sigma,
    vector rho
) {
    int m = dims(omega2)[1];
    int d = dims(omega2)[2];
    if (dims(rho)[1] != d) reject("brm_hsgp_sqrt_spd: dim mismatch — `rho` dim 1 (= ", dims(rho)[1], ") does not match `d` (= ", d, "), inferred from `omega2` dim 2. `d` sizes: `omega2` dim 2 (= ", dims(omega2)[2], "), `rho` dim 1 (= ", dims(rho)[1], ").");
    vector[m] rv;
    real scale = sigma;
    for(axis in 1:d) {
        scale *= sqrt((rho[axis] * 2.5066282746310002));
    }
    for(b in 1:m) {
        real exponent = 0.0;
        for(axis in 1:d) {
            exponent += (rho[axis] * rho[axis] * omega2[b, axis]);
        }
        rv[b] = (scale * exp((-0.25 * exponent)));
    }
    return rv;
}

    vector[num_elements(time)] pop_mu = (X_mu * pop_mu_beta_pop);
    vector[hsgp_time_n_axes] hsgp_time_rho = rep_vector(hsgp_time_rho_iso, hsgp_time_n_axes);
    vector[omega2_hsgp_time_m] hsgp_time_sqrt_spd = brm_hsgp_sqrt_spd(omega2_hsgp_time, hsgp_time_sigma, hsgp_time_rho);
    vector[PHI_hsgp_time_m] hsgp_time = (PHI_hsgp_time * (hsgp_time_sqrt_spd .* hsgp_time_beta_raw));
    vector[num_elements(time)] mu = (pop_mu + hsgp_time);
}

    pop_mu_beta_pop ~ normal([0]', [1]');
    hsgp_time_rho_iso ~ lognormal(0.0, 1.0);

}

Stan's adaptive wrapper supports ordinary Gaussian and R2D2 blocks, supported HSGP weights, CAR and S2Z cells. Grouped HSGP weights can use correlated levels and group-specific scales; their conditional ordering is fixed by the fitted levels. ranef_order=:learned applies to supported ordinary correlated blocks. Bounds that depend on other sampled parameters are outside the HSGP adaptive-scale surface. Extremely small spectral scales use a smooth numerical floor; controls observed only on that floor stay noncentered.

RK's wrapper currently covers ordinary Gaussian effects with sampled scales. Bounded or Student-t blocks, known level covariance and stratified group blocks have narrower support. Unsupported field cells pass through in their original frame. Check the prepared block inventory before assuming that every latent quantity adapts. SVI's learned centering optimizes its variational objective; it is a separate procedure, though its controls can initialize supported MCMC adaptation.

Adaptation does not guarantee greater efficiency. Check divergences, bulk and tail ESS, R-hat across independent chains, and agreement in scientific quantities. Compare the same posterior and count all fitting work. A short pilot that misses a region can select poor coordinates for a later fit.
