Wastewater and infection renewal ​

The data are CDC's public simulated example: wastewater RNA concentrations from a catchment of 400,000 people and daily hospital admissions in a state of 3,000,000 people. We use site 1 and the first 35 calendar days, from 1 September through 5 October 2023. Each wastewater record carries its sampling date, laboratory and detection limit; hospital records occupy a separate daily axis. The remaining state population has no wastewater observations. These are synthetic observations published by CDC's ww-inference-model, not measurements from a named community. The input tables and their exact source revision are linked under Reproduce.

Model ​

A shared weekly log reproduction number drives daily infection renewal. Each subpopulation follows that reference with its own stationary AR(1) deviation. Recent infections contribute infectiousness through a fixed generation-interval probability mass function. A feedback term attenuates the reproduction number as recent incidence increases:

Λk,t=∑s≥1gsIk,t−s,Ik,t=exp⁡(ℓt+δk,t−γΛk,t)Λk,t.

Here incidence is a daily population fraction. The reference has zero subpopulation deviation; its trajectory therefore anchors the hierarchy. Fifty unobserved days provide an exponentially seeded history before the first observation. Seven further days allow the fitted process to continue into a forecast. Neither the unobserved history nor the forecast contributes an extra observation likelihood.

The renewal recurrence is an ordinary StanBlocks function. This is the code the model calls, read from its source during the build:

julia
    renewal_feedback(logRt::vector[nt], g::vector[ng], gamma::real, I0::real,
                     r::real, n_seed::int)::vector[nt] = begin
        I::vector[nt]
        for t in 1:nt
            if t <= n_seed
                I[t] = I0 * exp(r * (t - 1))
            else
                conv = 0.0
                for s in 1:ng
                    prev = t - s >= 1 ? I[t - s] : 0.0
                    conv = conv + g[s] * prev
                end
                Rt = exp(logRt[t]) * exp(-gamma * conv)
                I[t] = Rt * conv
            end
        end
        I
    end

The @brm declaration keeps the population hierarchy, priors and observation families together. Its plate produces the infection trajectory of each subpopulation. Separate indexing arrays then connect each observed sample to the appropriate day, catchment and laboratory. Repeated measurements can share one latent infection value without duplicating that state.

function cdc_ww_brm_model(df = cdc_ww_brm_fixture())
    @brm df begin
        # Shared epidemic parameters. `dar` owns the zero-start differenced-AR
        # innovations while the intercept remains the initial weekly log-Rᵘ level.
        gamma       ~ LogNormal(-4.0, 0.5)
        phi_delta   ~ Beta(2.0, 8.0)
        sigma_delta ~ Exponential(4.0)
        log10_g     ~ Normal(12.0, 1.0)
        t_peak      ~ LogNormal(log(4.0), 0.25)
        viral_peak  ~ Normal(6.0, 1.0)
        shed_tail   ~ LogNormal(log(14.0), 0.3)
        dur_shed = t_peak + shed_tail
        shedding = viral_shedding_trajectory(t_peak, viral_peak, dur_shed, nsh)

        log_ru_week ~ 1 + dar(week_grid; p = 1)
        effect(log_ru_week, Intercept) ~ Normal(0.0, 0.5)
        log_ru = weekly_expand(log_ru_week, week_idx)

        # Hierarchical incidence and initial growth are defined over the latent
        # subpopulation axis, including the uncovered reference population.
        logit_I0      ~ 1 + (1 | initial | subpopulation)
        initial_growth ~ 1 + (1 | growth | subpopulation)
        effect(logit_I0, Intercept) ~ Normal(-9.0, 1.0)
        effect(initial_growth, Intercept) ~ Normal(0.0, 0.05)
        sd(:, initial) ~ Normal(0.0, 0.75)
        sd(:, growth) ~ Normal(0.0, 0.05)

        # The plate produces latent trajectories only, one per subpopulation.
        # Observation frames are mapped onto this matrix after the plate.
        @plate for k in eachindex(logit_I0)
            eps_d ~ Normal(zeros(n_total), 1.0)             # this subpopulation's daily innovations
            delta_k = ar1_dev(eps_d, phi_delta, sigma_delta)
            log_rt_k = log_ru .+ (1.0 - is_reference[k]) .* delta_k
            I_mat[k] = renewal_from_first_observed(log_rt_k, g, gamma,
                                                   logistic(logit_I0[k]), initial_growth[k], uot)
        end

        # Sparse wastewater records have independent time, subpopulation, lab
        # and record-specific LOD mappings. Multiple labs may observe the same
        # catchment/time pair; the reference population may have no records.
        log_lab_mod ~ 0 + (1 | ww_scale | ww_lab)
        log_sigma_ww ~ 1 + (1 | ww_noise | ww_lab)
        effect(log_sigma_ww, Intercept) ~ Normal(log(0.35), 0.5)
        sd(:, ww_scale) ~ Normal(0.0, 0.5)
        sd(:, ww_noise) ~ Normal(0.0, 0.35)
        ww_mu = ww_expected_log(I_mat, shedding, ww_time, ww_subpop, ww_obs_lab,
                                log_lab_mod, log10_g, mwpd)
        ww_sigma = gather_exp(log_sigma_ww, ww_obs_lab)
        ww_log_conc ~ censored(Normal(ww_mu, ww_sigma); lower = ww_lod)

        # jurisdiction aggregate infections (population-weighted across subpops)
        I_agg = wsum(I_mat, w)

        # Count-stream module. Each stream gets a hierarchical rate center and a
        # stationary weekly AR deviation. Observation rows can be daily or span
        # arbitrary inclusive intervals and can map different latent catchments.
        phi_count ~ Beta(2.0, 8.0)
        sigma_count ~ Exponential(20.0)
        count_rate_center ~ 1 + (1 | count_rate | count_stream)
        effect(count_rate_center, Intercept) ~ Normal(-4.6, 0.3)
        sd(:, count_rate) ~ Normal(0.0, 0.5)
        @plate for s in eachindex(count_rate_center)
            eps_count ~ Normal(zeros(n_weeks), 1.0)         # this stream's weekly innovations
            count_rate_week[s] = count_rate_center[s] .+ ar1_dev(eps_count, phi_count, sigma_count)
        end
        count_rate_daily = weekly_expand_columns(count_rate_week, week_idx)
        dow_share ~ Dirichlet(7, 5.0)
        dow_effect = scale_simplex(dow_share, 7.0)
        log_phi_count ~ 1 + (1 | count_dispersion | count_stream)
        effect(log_phi_count, Intercept) ~ Normal(log(15.0), 0.5)
        sd(:, count_dispersion) ~ Normal(0.0, 0.5)
        count_mu = count_interval_mean(I_mat, count_subpop_weights, count_delay,
                                       count_rate_daily, count_start, count_stop,
                                       count_obs_stream, dow, dow_effect,
                                       count_population)
        count_phi = gather_exp(log_phi_count, count_obs_stream)
        count ~ NegativeBinomial2(count_mu, count_phi)

        # Forecast contract: named deterministic carriers use the same fitted
        # latent state and observation mappings but are not calibration outcomes.
        forecast_infections = take_window(I_agg, uot + nt + 1, ht)
        forecast_count_mean = count_interval_mean(
            I_mat, count_subpop_weights, count_delay, count_rate_daily,
            forecast_count_start, forecast_count_stop,
            forecast_count_obs_stream, dow, dow_effect, count_population)
        forecast_ww_log_mean = ww_expected_log(
            I_mat, shedding, forecast_ww_time, forecast_ww_subpop,
            forecast_ww_obs_lab, log_lab_mod, log10_g, mwpd)
    end
end

"""
Group-level (varying) effects of grouping `g`.

Non-centered, from the scale `tau[1]` (drawn from its prior) and standardized effects
`z[1:length(levels(g)), 1:1] ~ Normal(0, 1)`. Returns the
level-by-margin matrix `z .* tau[1]`, one row per level of `g` in order.
"""
brm_group_effects(g) = begin
        tau[1:1] .~ restricted.(Normal(0.0, 0.75), 0.0, Inf)
        z[1:length(levels(g)), 1:1] .~ Normal.(0, 1)
        return z .* tau[1]
    end

"""
A differenced AR(1) level path over `T` steps (`dar`).

Draws the persistence `beta` and innovation scale `sigma` from their priors.
The path starts at `level[1] = increment[1] = 0`; then
`increment[t] = beta * increment[t - 1] + sigma * innovation` with
`innovation ~ Normal(0, 1)`, and `level[t] = level[t - 1] + increment[t]`.
Returns the level path `level`.
"""
brm_differenced_ar1(T) = begin
        beta ~ truncated(Normal(0.5, 0.2), 0, 1)
        sigma ~ HalfNormal(0.2)
        @scan begin
                level[1] = 0.0
                increment[1] = 0.0
                for t = 2:T
                    innovation ~ Normal(0, 1)
                    increment[t] = beta * increment[t - 1] + sigma * innovation
                    level[t] = level[t - 1] + increment[t]
                end
            end
        return level
    end

    int n
) {
    vector[n] s;

The plotted quantity is the exponentiated shared reference process, before infection feedback and catchment-specific deviations. It is not the realized reproduction number of the measured catchment. Its bands describe uncertainty in that latent reference, rather than a prediction interval for a future concentration. Convolution and sparse sampling mean that a short change in wastewater need not imply an equally sharp change in transmission.

This example uses BRM's structural port of the CDC model. The recurrence, subpopulation hierarchy, shedding and count streams follow the same causal order; the priors and hospitalization-rate parameterization are those of the checked-in BRM declaration. This fit is not a reproduction of CDC's posterior estimates. The research notes give the differences and retain the smaller EpiSewer-style model for comparison.

Commands and fit receipt

The repository's test environment supplies the pinned BRM, StanBlocks, BridgeStan, WarmupHMC and TreeArrays dependencies. These shell commands are manual: the docs build executes the model declarations and figures but reads the completed fit's summaries. Run the fit deliberately when its model, data or settings change; routine documentation edits reuse the cache.

sh
julia --startup-file=no --project=test test/setup_env.jl
julia -t 4 --startup-file=no --project=test research/wastewater/fit.jl

The script writes its receipt before sampling and saves the draws outside the repository. Its key includes the emitted program, data, settings, seed and sampling harness. TreeArrays reduces the named chain and draw axes to small summary tables. A second invocation with the same key rebuilds those tables from the saved draws. The receipt identifies the program behind these numbers.

On a fresh checkout the draws may be absent. An existing receipt guards against repeating a recent fit; set BRM_DOCS_FIT_FORCE=1 for a deliberate rerun. BRM_DOCS_CACHE selects a persistent draw-cache directory; its default is under the system temporary directory. Only the small summary tables belong in git.
