Backends and model inspection ​

Lower one declaration to a Julia density, a Stan program or a Python/JAX module. Inspect the intermediate representation and effective priors before choosing a fitting method.

The lowering chain ​

An @brm builder binds data into a BRMI, a typed collection of declarations, assignments, prior selectors and data. It has not fitted the model. Each backend consumes these same operations and records the fitted preprocessing needed to evaluate new rows consistently.

Entry pointResultUses
SBBRMI(model)StanBlocks representation and emitted StanBridgeStan density and gradients; Stan generated quantities
RKBRMI(model)ReactiveKernelsPPL programJulia density and gradients; MCMC, variational inference, filters and JAX export

The backends share formula interpretation; their supported terms, custom functions and prediction surfaces differ. See the terms reference for individual contracts. Start with RK for a Julia workflow and use Stan when a needed term or observation mechanism is supported there.

"""
Group-level (varying) effects of grouping `g`.

Non-centered, from the scale `tau[1]` (drawn from its prior) and standardized effects
`z[1:length(levels(g)), 1:1] ~ Normal(0, 1)`. Returns the
level-by-margin matrix `z .* tau[1]`, one row per level of `g` in order.
"""
brm_group_effects(g) = begin
        tau[1:1] .~ Exponential.(0.5)
        z[1:length(levels(g)), 1:1] .~ Normal.(0, 1)
        return z .* tau[1]
    end

"""
Population-level effects: one coefficient per column of the design matrix `X`.

Draws `beta_pop[1:ncoef] ~ Normal(loc, scale)` and returns the linear predictor
`X * beta_pop`. `ncoef` is the number of columns of `X`. Each prior argument (`loc`, `scale`) is one value for all coefficients or a vector with one per coefficient.
"""
brm_population_effects(X, ncoef, loc, scale) = begin
        beta_pop[1:ncoef] .~ Normal.(loc, scale)
        return X * beta_pop
    end

begin
    subject_fit_levels = brm_fit_levels(subject_fit)
    b_mu__subject_subject ~ brm_group_effects(subject_fit_levels)
    subject_level = brm_level_indices(subject, subject_fit_levels)
    ranef_mu_mu__subject_subject = b_mu__subject_subject[subject_level, 1]
    X_mu = hcat(ones(length(subject)), x)
    pop_mu ~ brm_population_effects(X_mu, 2, 0.0, [1.0, 0.5])
    mu = pop_mu .+ ranef_mu_mu__subject_subject
    sigma ~ Exponential(0.3)
    y .~ Normal.(mu, sigma)
end

def _rk_order_key_np(x):
    # Julia's isless order of an array as sortable keys: a float is an integer
    # key, -0.0 before 0.0 and every NaN last, equal for values isequal treats
    # as equal. Integer and string arrays are their own keys.
    x = np.asarray(x)
    if x.dtype.kind != "f":
        return x
    bits = np.where(np.isnan(x), np.nan, x).astype(np.float64).view(np.int64)
    return np.where(bits < 0, bits ^ np.int64(0x7FFFFFFFFFFFFFFF), bits)


def _rk_unique_np(x):
    # Julia's unique of a vector: the first value of each isequal class, in
    # order.
    x = np.asarray(x)
    _, first = np.unique(_rk_order_key_np(x), return_index=True)
    return x[np.sort(first)]


def _rk_sort_np(x):
    # Julia's sort of a vector: ascending in isless order, equal values in
    # their order.
    x = np.asarray(x)
    return x[np.argsort(_rk_order_key_np(x), kind="stable")]


def _brm_sorted_labels_np(source):
    labels = _rk_unique_np(source)
    sorted_ = _rk_sort_np(labels)
    return sorted_


def _brm_fit_levels_np(source):
    value = _brm_sorted_labels_np(source)
    levels = value
    return levels


def _brm_level_indices_np(labels, source):
    value = _brm_fit_levels_np(source)
    levels = value
    lookup = {}
    for k in range(1, len(levels) + 1):
        lookup[levels[k - 1]] = k
    indices = np.zeros((len(labels),), dtype=np.int64)
    for r in range(1, len(labels) + 1):
        position = lookup.get(labels[r - 1], 0)
        if position == 0:
            raise ValueError("".join([str("RK backend: group label `"), str(labels[r - 1]), str("` is not one of the "), str(len(levels)), str(" fitted levels. A replay keeps the fitted levels of every grouping it does not resample; name the grouping in `resample_groups` to take the new data's own levels.")]))
        indices[r - 1] = position
    return indices


def _rk_levels_np(x):
    arr = np.asarray(x)
    values = sorted(set(v for v in arr.tolist() if v is not None))
    return np.array(values, dtype=object if arr.dtype == object else arr.dtype)


class StaticInt(int):
    """An integer of the prepared data that sets a shape.

    It is an `int` everywhere, and `jax.jit` treats it as static, so the
    functions jit with the prepared data as arguments; a new value traces
    them again.

    def __repr__(self):
        return "StaticInt(%d)" % int(self)

    def then_arm_2():

    """The log prior density of the constrained parameters at `unconstrained`, the packed unconstrained parameters (length `dimension(prepared)`), for the data `prepare_data` returned: `f(u, **prepared)`."""
    ppl_last_b_mu_subject_subject_z = prepared["ppl_last_b_mu_subject_subject_z"]
    ppl_axis1_b_mu_subject_subject_z = prepared["ppl_axis1_b_mu_subject_subject_z"]

    ppl_last_pop_mu_beta_pop = prepared["ppl_last_pop_mu_beta_pop"]
    X_mu = prepared["X_mu"]
    subject_level = prepared["subject_level"]
    y = prepared["y"]
    unconstrained = jnp.asarray(unconstrained)
    X_mu = jnp.asarray(X_mu)
    subject_level = jnp.asarray(subject_level)
    y = jnp.asarray(y)
    scale_binding = 0.3
    ppl_prior_sigma_log_scale = np.log(scale_binding)
    ppl_parg_pop_mu_beta_pop_2 = jnp.asarray([1.0, 0.5], dtype=jnp.float64)
    u_argument = unconstrained[0]
    constrain = jnp.exp(u_argument)
    plate_argument = unconstrained[1:2]
    def cell(ppl_cell_b_mu_subject_subject_tau):
        constrain_2 = jnp.exp(ppl_cell_b_mu_subject_subject_tau)
        return constrain_2
    b_mu_subject_subject_tau = (jnp.zeros(plate_argument.shape[:1], dtype=jnp.float64) if 0 in plate_argument.shape[:1] else jax.vmap(cell, in_axes=(0,))(plate_argument))
    ppl_arrflat_b_mu_subject_subject_z = unconstrained[2:ppl_last_b_mu_subject_subject_z]
    pop_mu_beta_pop = unconstrained[ppl_first_pop_mu_beta_pop - 1:ppl_last_pop_mu_beta_pop]
    def then_arm():
        return -jnp.inf
    def else_arm():
        return -ppl_prior_sigma_log_scale - constrain / scale_binding
    logpdf = jax.lax.cond(constrain < 0, then_arm, else_arm)
    def cell_2(b_mu_subject_subject_tau_2):
        scale_binding_2 = 0.5
        log_scale = np.log(scale_binding_2)
        def then_arm_2():
            return -jnp.inf
        def else_arm_2():
            return -log_scale - b_mu_subject_subject_tau_2 / scale_binding_2
        logpdf_2 = jax.lax.cond(b_mu_subject_subject_tau_2 < 0, then_arm_2, else_arm_2)
        return logpdf_2
    ppl_pw_prior_b_mu_subject_subject_tau = (jnp.zeros(b_mu_subject_subject_tau.shape[:1], dtype=jnp.float64) if 0 in b_mu_subject_subject_tau.shape[:1] else jax.vmap(cell_2, in_axes=(0,))(b_mu_subject_subject_tau))
    ppl_prior_b_mu_subject_subject_tau = jnp.sum(ppl_pw_prior_b_mu_subject_subject_tau)
    def cell_3(b_mu_subject_subject_z):
        location_binding = 0.0
        scale_binding_2 = 1.0
        log_scale = np.log(scale_binding_2)
        def then_arm_2():
            return b_mu_subject_subject_z == location_binding
        def else_arm_2():
            return False
        value = (then_arm_2() if scale_binding_2 == 0 else else_arm_2())
        def then_arm_3():
            return 1.0
        def else_arm_3():
            return scale_binding_2
        standardized = (b_mu_subject_subject_z - location_binding) / jax.lax.cond(value, then_arm_3, else_arm_3)
        standard_logpdf = -0.5 * np.log(2 * np.pi) - 0.5 * standardized ** 2
        def then_arm_4():
            return b_mu_subject_subject_z != location_binding
        def else_arm_4():
            return False
        value_2 = (then_arm_4() if scale_binding_2 == 0 else else_arm_4())
        def then_arm_5():
            return 0.0
        def else_arm_5():
            return log_scale
        logpdf_2 = standard_logpdf - jax.lax.cond(value_2, then_arm_5, else_arm_5)
        return logpdf_2
    ppl_pw_prior_b_mu_subject_subject_z = (jnp.zeros(ppl_arrflat_b_mu_subject_subject_z.shape[:1], dtype=jnp.float64) if 0 in ppl_arrflat_b_mu_subject_subject_z.shape[:1] else jax.vmap(cell_3, in_axes=(0,))(ppl_arrflat_b_mu_subject_subject_z))
    ppl_prior_b_mu_subject_subject_z = jnp.sum(ppl_pw_prior_b_mu_subject_subject_z)
    def cell_4(pop_mu_beta_pop_2, scale):
        location_binding = 0.0
        log_scale = jnp.log(scale)
        def then_arm_2():
            return 1.0
        def else_arm_2():
            return scale
        standardized = (pop_mu_beta_pop_2 - location_binding) / jax.lax.cond(jnp.logical_and(scale == 0, pop_mu_beta_pop_2 == location_binding), then_arm_2, else_arm_2)
        standard_logpdf = -0.5 * np.log(2 * np.pi) - 0.5 * standardized ** 2
        def then_arm_3():
            return 0.0
        def else_arm_3():
            return log_scale
        logpdf_2 = standard_logpdf - jax.lax.cond(jnp.logical_and(scale == 0, pop_mu_beta_pop_2 != location_binding), then_arm_3, else_arm_3)
        return logpdf_2
    ppl_pw_prior_pop_mu_beta_pop = (jnp.zeros(pop_mu_beta_pop.shape[:1], dtype=jnp.float64) if 0 in pop_mu_beta_pop.shape[:1] and ppl_parg_pop_mu_beta_pop_2.shape[:1] == pop_mu_beta_pop.shape[:1] else jax.vmap(cell_4, in_axes=(0, 0))(pop_mu_beta_pop, ppl_parg_pop_mu_beta_pop_2))
    ppl_prior_pop_mu_beta_pop = jnp.sum(ppl_pw_prior_pop_mu_beta_pop)
    prior = logpdf + ppl_prior_b_mu_subject_subject_tau + ppl_prior_b_mu_subject_subject_z + ppl_prior_pop_mu_beta_pop
    def then_arm_2():
        return None
    def else_arm_2():
        raise ValueError("[layout] packed length ≠ layout total: a packed point holds the coordinates of the binding whose layout packed it")
        return None
    value = (then_arm_2() if unconstrained.size == ppl_last_pop_mu_beta_pop else else_arm_2())
    return prior

    ppl_axis1_b_mu_subject_subject_z = prepared["ppl_axis1_b_mu_subject_subject_z"]
    ppl_first_pop_mu_beta_pop = prepared["ppl_first_pop_mu_beta_pop"]

    X_mu = prepared["X_mu"]

    unconstrained = jnp.asarray(unconstrained)
    X_mu = jnp.asarray(X_mu)

    b_mu_subject_subject_z = jnp.reshape(ppl_arrflat_b_mu_subject_subject_z, (ppl_axis1_b_mu_subject_subject_z, 1), order="F")
    pop_mu_beta_pop = unconstrained[ppl_first_pop_mu_beta_pop - 1:ppl_last_pop_mu_beta_pop]
    b_mu_subject_subject = b_mu_subject_subject_z * b_mu_subject_subject_tau[0]
    ppl_column_b_mu_subject_subject_1 = b_mu_subject_subject[:, 0]
    pop_mu = X_mu @ pop_mu_beta_pop
    plate_argument_2 = ppl_column_b_mu_subject_subject_1[subject_level - 1]

        return None
    value = (then_arm() if unconstrained.size == ppl_last_pop_mu_beta_pop else else_arm())

Replay and outputs ​

Keep the prepared model with its fit. reprocess binds new rows while retaining fitted factor levels, centering and scaling constants, group structure and basis information. Rebuilding from an unbound formula can change those constants and therefore change the meaning of a posterior draw.

Use declared output paths when reading predictions or latent quantities. brm_outputs and brm_output expose a Stan descriptor's output inventory. RK's rk_draw_values and rk_draw_tree evaluate requested quantities from model-coordinate draws. A latent field, a linear predictor and a predictive response are different outputs; adding observation noise belongs to prediction.

Python/JAX export ​

Export the RK program together with its bound plan. The generated module owns its data preparation and unconstrained-coordinate layout. Keep the bound inputs with it; the Python source alone does not contain the data.

The accessor returns exactly the module's DATA inputs, including scalar constants by their authored names. In Python, call prepare_data(**inputs), then log_density with an unconstrained position. JAX can differentiate and compile that density. A Julia callable needs a supported translation; inspect the generated UNTRANSLATED report before using an export.
