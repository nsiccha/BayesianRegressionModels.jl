Sequential Monte Carlo and filtering ​

Fit an initial count series with SMC, update it with new counts, and compare online state estimates and parameter uncertainty with a full-data MCMC fit.

Daily counts ​

The synthetic data contain daily Poisson counts from units with separate log-rate offsets and latent paths, with shared autoregressive parameters. The generator records the latent paths, so filtered intervals can be compared with their known values. Persistence is rho; innovation standard deviation is tau.

function filtering_model(data=filtering_fixture(; units=2, days=6).data)
    @brm data begin
        level ~ Normal(level_location, level_scale)
        offset[1:U] .~ Normal.(offset_location, offset_scale)
        rho ~ Beta(rho_alpha, rho_beta)
        tau ~ Exponential(tau_scale)
        @plate for i in eachindex(y)
            @scan begin
                state[1] ~ Normal(state_location, state_scale)
                for t in 2:T
                    state[t] ~ Normal(rho * state[t - 1], tau)
                end
            end
            y[i] ~ Poisson(exposure[i] .* exp.(level + offset[i] .+ state))
        end
    end
end

def _rk_pad_rows(rows, dtype):
    # A ragged value as the functions take it: the padded array (each row
    # repeats its last entry; an empty row is zeros), the lengths, and the
    # positions of the valid entries in the flattened padded array, whose
    # length is the total. `dtype` is the element type the program declares,
    # so an empty row (`[]`) keeps an integer column integer.
    rows = [np.asarray(r, dtype=dtype) for r in rows]
    lengths = np.asarray([r.shape[0] for r in rows], dtype=np.int64)
    width = max([1] + [int(n) for n in lengths])
    padded = np.stack([np.pad(r, (0, width - r.shape[0]), mode="edge") if r.shape[0] > 0
                       else np.zeros(width, dtype=dtype) for r in rows]) if rows else np.zeros((0, width), dtype=dtype)
    flat = np.flatnonzero(np.arange(width)[None, :] < lengths[:, None])
    return padded, lengths, flat


def _rk_lgamma_correction(x):
    # log(gamma(x)) - ((x - 0.5) * log(x) - x + 0.5 * log(2 pi)), for x >= 10:
    # the Stirling series through x^-15.
    z = 1.0 / (x * x)
    return (1.0 / x) * (1.0 / 12 + z * (-1.0 / 360 + z * (1.0 / 1260 + z * (-1.0 / 1680
        + z * (1.0 / 1188 + z * (-691.0 / 360360 + z * (1.0 / 156 + z * (-3617.0 / 122400))))))))


def _rk_logbeta(a, b):
    # SpecialFunctions.logbeta for positive arguments. With b the larger, a
    # large b subtracts log(gamma(b)) - log(gamma(a + b)) in Stirling form,
    # without cancellation.
    a, b = jnp.minimum(a, b), jnp.maximum(a, b)
    small = jsp.gammaln(a) + jsp.gammaln(b) - jsp.gammaln(a + b)
    big = jnp.maximum(b, 10.0)
    large = (jsp.gammaln(a) + _rk_lgamma_correction(big) - _rk_lgamma_correction(a + big)
             - (a + big - 0.5) * jnp.log1p(a / big) - a * jnp.log(big) + a)
    return jnp.where(b < 10, small, large)

Missing observations advance selected groups without conditioning; omitted groups do not advance. Declare new per-step covariates in inputs.

Learn the static parameters while filtering ​

julia
calibration = brm_smc_carry(fit; parameters=:filter,
    inputs=(:exposure,), basis=:correlation)
learning = brm_filter(calibration, filtering_model(training);
    boundary=warm, groups=(i=1:data.U,), rng=Xoshiro(402),
    members=256, particles=128, window_length=10,
    options=SMCOptions(moves=3, max_tree_depth=7))
learning = brm_filter_stream(learning, records[21:end])

parameters=:filter retains only static coordinates, dropping the historical latent path. basis=:correlation fits their correlation structure. The warmed boundary supplies state particles and clocks independently of the new parameter members. A learning filter cannot itself perform state-only warm-up.

New observations reweight members; replenishment and particle-Metropolis moves restore diversity within the retained window. At a boundary, a Gaussian summarizes the parameter posterior and an independent pool summarizes the states. That discards parameter–state dependence. This is assumed-density inference, rather than exact full-history SMC². Read weighted parameter positions from state.positions and state.parameter_mass, and inspect state.history for replenishment and boundary resets.

Checkpoints ​

Bound work by completed stages, save a checkpoint, and reconstruct the original training model to resume:

julia
partial = brm_smc_update(fit, cumulative; stages=1,
    options=SMCOptions(tuning=bridge))
serialize("smc-checkpoint.jls", brm_smc_checkpoint(partial))

rk = RKBRMI(filtering_model(training))
restored = brm_smc_resume(rk, deserialize("smc-checkpoint.jls"); data=cumulative)
completed = brm_smc_fit(restored)

After later cumulative updates, also supply previous_data for the immediately preceding cumulative dataset. A carried-window checkpoint needs only that window and its model declaration:

julia
restored_window = brm_smc_resume(filtering_model(window), brm_smc_checkpoint(window_fit))
restored_filter = brm_filter_resume(rk, brm_filter_checkpoint(next))

Checkpoints retain particle state and identity records. Keep model code and data separately and retain the numerical environment: endpoint densities must reproduce exactly. Only deserialize trusted files. Production checkpoints preserve completed tuning; interrupted pilots need their own checkpoint_dir and tuning-resume path.

If moving a production checkpoint to another CPU changes endpoint scores only by roundoff, explicitly rescore it on the destination host before resuming (BRM 0.2.279, ReactiveKernelsPPL 0.1.156):

julia
checkpoint = deserialize("smc-checkpoint.jls")
rescored = brm_smc_rescore(rk, checkpoint; data=cumulative, rtol=1e-10)
last(rescored.state.rescored)  # changed, max_abs, max_rel, rtol, codegen
serialize("smc-checkpoint-rescored.jls", rescored)
restored = brm_smc_resume(rk, rescored; data=cumulative)

Each score must differ by at most rtol * max(abs(saved_score), 1). The returned checkpoint records the change in rescored.state.rescored; the input stays unchanged. Resume still requires exact scores. Rescore keeps all model, data, version and state checks and cannot migrate an older-version checkpoint. It uses the same reconstruction arguments as resume: previous_data for later cumulative updates, model::BRMI for a carried window (including compact coordinates), or a Laplace problem with current and, when needed, previous. Tuning-pilot checkpoints have no rescore adapter.

A whole series as a likelihood ​

A filter can also run inside a model likelihood. A plate cell then observes one unit's whole series under a law that integrates its time-local states out. Outer MCMC or variational inference fits the remaining parameters, and each density evaluation runs the filter over that unit's series. This differs from brm_filter_step, which advances an already fitted model online.

The continuous-time state-space example shows the model declarations and filter bodies for this approach, including Kalman and nonlinear approximations and checks of the approximation's accuracy.
