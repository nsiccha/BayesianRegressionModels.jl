Spatial and space-time fields ​

Share information between nearby observations, neighboring areas or related measurement channels. Choose a representation from the observation geometry and the predictions you need.

DataTermRepresentation
Areas with known neighborscar(area; edges=(from,to), type=:bym2)Graph field plus independent area effects
Smooth continuous coordinateshsgp(east,north; k=(kx,ky))Fixed Hilbert basis with kx*ky weights
Points evolving over timegmrf((east,north),time; mesh=...)Triangular-mesh Matérn field with OU evolution
Sparse irregular position–time readsgmrf((east,north),time; neighbors=m)Local Gaussian conditionals on the observed states
Irregular reads needing exact OU time covariancegmrf((east,north),time; multiresolution=m)Sparse spatial basis of shared OU paths

Use a common planar distance unit. Longitude and latitude in degrees need a suitable projection before they represent distances in these terms.

Areal effects ​

ICAR shares information through adjacency. BYM2 adds independent area effects and estimates the structured variance share. The intercept carries the overall level; an exposure offset keeps the field on a relative-risk scale.

real brm_icar_lpdf(
    vector phi,
    array[] int node1,
    array[] int node2,
    array[] int comp_start,
    array[] int comp_size
) {
    int E = dims(node1)[1];
    int C = dims(comp_start)[1];
    if (dims(node2)[1] != E) reject("brm_icar_lpdf: dim mismatch — `node2` dim 1 (= ", dims(node2)[1], ") does not match `E` (= ", E, "), inferred from `node1` dim 1. `E` sizes: `node1` dim 1 (= ", dims(node1)[1], "), `node2` dim 1 (= ", dims(node2)[1], ").");
    if (dims(comp_size)[1] != C) reject("brm_icar_lpdf: dim mismatch — `comp_size` dim 1 (= ", dims(comp_size)[1], ") does not match `C` (= ", C, "), inferred from `comp_start` dim 1. `C` sizes: `comp_start` dim 1 (= ", dims(comp_start)[1], "), `comp_size` dim 1 (= ", dims(comp_size)[1], ").");
    real lp = (-0.5 * dot_self((phi[node1] - phi[node2])));
    for(c in 1:C) {
        lp += normal_lpdf(sum(segment(phi, comp_start[c], comp_size[c])) | 0.0, (0.001 * comp_size[c]));
    }
    return lp;
}
vector car_bym2_effects(
    real sigma,
    real rho,
    vector phi,
    vector theta,
    array[] int struct_idx,
    vector inv_scale
) {
    int N = dims(theta)[1];
    if (dims(struct_idx)[1] != N) reject("car_bym2_effects: dim mismatch — `struct_idx` dim 1 (= ", dims(struct_idx)[1], ") does not match `N` (= ", N, "), inferred from `theta` dim 1. `N` sizes: `theta` dim 1 (= ", dims(theta)[1], "), `struct_idx` dim 1 (= ", dims(struct_idx)[1], "), `inv_scale` dim 1 (= ", dims(inv_scale)[1], ").");
    if (dims(inv_scale)[1] != N) reject("car_bym2_effects: dim mismatch — `inv_scale` dim 1 (= ", dims(inv_scale)[1], ") does not match `N` (= ", N, "), inferred from `theta` dim 1. `N` sizes: `theta` dim 1 (= ", dims(theta)[1], "), `struct_idx` dim 1 (= ", dims(struct_idx)[1], "), `inv_scale` dim 1 (= ", dims(inv_scale)[1], ").");
    vector[N] out;
    for(k in 1:N) {
        out[k] = (sqrt((1.0 - (rho * (struct_idx[k] > 0)))) * theta[k]);
        if((struct_idx[k] > 0)) {
            out[k] += (sqrt((rho * inv_scale[k])) * phi[struct_idx[k]]);
        }
    }
    return (sigma * out);
}

Smooth surfaces and channels ​

HSGP uses a squared-exponential covariance, smoother than the Matérn field below. iso=true shares a length across axes; iso=false gives each axis its own. by=channel allocates weights per channel, and cor=Omega correlates matching weights between channels.

functions {
real conditioning_lognormal_lpdf(
    real y,
    real lo,
    int hi,
    real args1,
    real args2
) {
    array[1] real rv;
    rv[1] = negative_infinity();
    if((lo >= hi)) {
        reject("truncated: lower bound must be less than upper bound");
    } else {
        if((y >= lo)) {
            if((y <= hi)) {
                rv[1] = (
                    lognormal_lpdf(y | args1, args2) -
                    log_diff_exp(lognormal_lcdf_stable(hi, args1, args2), lognormal_lcdf_stable(lo, args1, args2))
                );
            }
        }
    }
    return rv[1];
}
real lognormal_lcdf_stable(
    int y,
    real mu,
    real sigma
) {
    return ((y <= 0) ? negative_infinity() : (is_inf(y) ? 0.0 : normal_lcdf_stable(log(y), mu, sigma)));
}
real normal_lcdf_stable(
    real x,
    real loc,
    real scale
) {
    return (is_inf(x) ? ((x < 0) ? negative_infinity() : 0.0) : ((((x - loc) / scale) < -35) ? std_normal_lcdf_tail(((x - loc) / scale)) : ((((x - loc) / scale) <= 0) ? (log(erfc(((-(x - loc)) / (scale * sqrt(2.0))))) - log(2.0)) : log1m((0.5 * erfc(((x - loc) / (scale * sqrt(2.0)))))))));
}
real std_normal_lcdf_tail(
    real z
) {
    return ((-0.5 * square(z)) + std_normal_scaled_lcdf_tail(z));
}
real std_normal_scaled_lcdf_tail(
    real z
) {
    real w = inv(square(z));
    return (
        ((-log((-z))) - 0.9189385332046728) +
        log1p((w * (-1 + (w * (3 + (w * (-15 + (w * (105 + (w * (-945 + (w * 10395))))))))))))
    );
}

vector brm_hsgp_sqrt_spd(
    matrix omega2,
    real sigma,
    vector rho
) {
    int m = dims(omega2)[1];
    int d = dims(omega2)[2];
    if (dims(rho)[1] != d) reject("brm_hsgp_sqrt_spd: dim mismatch — `rho` dim 1 (= ", dims(rho)[1], ") does not match `d` (= ", d, "), inferred from `omega2` dim 2. `d` sizes: `omega2` dim 2 (= ", dims(omega2)[2], "), `rho` dim 1 (= ", dims(rho)[1], ").");
    vector[m] rv;
    real scale = sigma;
    for(axis in 1:d) {
        scale *= sqrt((rho[axis] * 2.5066282746310002));
    }
    for(b in 1:m) {
        real exponent = 0.0;
        for(axis in 1:d) {
            exponent += (rho[axis] * rho[axis] * omega2[b, axis]);
        }
        rv[b] = (scale * exp((-0.25 * exponent)));
    }
    return rv;
}
vector brm_hsgp_by_level_rows(
    matrix PHI_by_level,

    vector[n] rv;

    while((first_row <= n)) {

}

All representations support full-model MCMC on RK and Stan. RK mesh fields may live in independent plate cells; the cell predictor must be 0 + gmrf, and shared channel correlation belongs outside the cell. Neighbor fields do not use that plate or embedded-Laplace surface. field_states=:units lets supported field states become SVI units; see the SVI example. Embedded Laplace is an explicit mesh integration choice. Large operator solves use a fixed-probe determinant estimate, so even a Gaussian integral can be approximate. Check the solver and probe settings against the accuracy needed for the fit. The representation notes retain the precision derivations and synthetic benchmark protocols.
