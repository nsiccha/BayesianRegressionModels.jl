Space-time Gaussian Markov fields ​

gmrf((east, north), time, channel; mesh, cor=Omega) contributes a spatial Matérn field with stationary Ornstein–Uhlenbeck (OU) evolution in time. Each observation reads three vertices of a triangular mesh at its own time and channel. The latent field has a normalized joint Gaussian prior, including the determinants that depend on its spatial length, temporal length and channel correlation.

Declare the field and its priors ​

Supply planar coordinates and a triangular mesh in the same units. The vertex matrix has two columns; each row of the integer cell matrix contains three one-based vertex indices. The example uses a tiny mesh to show the syntax. A mesh for scientific use needs a resolution and boundary buffer appropriate to the spatial range prior.

Matérn space × OU time × correlated channels

small_field = (@brm begin
    Omega ~ LKJCholesky(2, 2.0)
    field ~ 0 + gmrf((east, north), time, channel;

    sd(field, gmrf((east, north), time, channel)) ~ Exponential(0.7)
    length_scale(field, gmrf((east, north), time, channel), space) ~ LogNormal(log(0.4), 0.4)

real brm_gmrf_logdensity(
    vector field,
    real spatial_length,
    real temporal_length,
    matrix L,
    vector times,
    array[] int permutation,
    vector mass,
    array[] int gptr,
    array[] int grow,
    vector gval,
    array[] int lptr,
    array[] int lrow,
    array[] int previous_ptr,
    array[] int previous_col,
    array[] int previous_pos
) {
    int D = dims(field)[1];
    int C = dims(L)[1];
    int T = dims(times)[1];
    int N = dims(permutation)[1];
    int NP = dims(gptr)[1];
    int NZ = dims(grow)[1];
    int ND = dims(previous_col)[1];
    if (dims(L)[2] != C) reject("brm_gmrf_logdensity: dim mismatch — `L` dim 2 (= ", dims(L)[2], ") does not match `C` (= ", C, "), inferred from `L` dim 1. `C` sizes: `L` dim 1 (= ", dims(L)[1], "), `L` dim 2 (= ", dims(L)[2], ").");
    if (dims(mass)[1] != N) reject("brm_gmrf_logdensity: dim mismatch — `mass` dim 1 (= ", dims(mass)[1], ") does not match `N` (= ", N, "), inferred from `permutation` dim 1. `N` sizes: `permutation` dim 1 (= ", dims(permutation)[1], "), `mass` dim 1 (= ", dims(mass)[1], ").");
    if (dims(lptr)[1] != NP) reject("brm_gmrf_logdensity: dim mismatch — `lptr` dim 1 (= ", dims(lptr)[1], ") does not match `NP` (= ", NP, "), inferred from `gptr` dim 1. `NP` sizes: `gptr` dim 1 (= ", dims(gptr)[1], "), `lptr` dim 1 (= ", dims(lptr)[1], "), `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ").");
    if (dims(previous_ptr)[1] != NP) reject("brm_gmrf_logdensity: dim mismatch — `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ") does not match `NP` (= ", NP, "), inferred from `gptr` dim 1. `NP` sizes: `gptr` dim 1 (= ", dims(gptr)[1], "), `lptr` dim 1 (= ", dims(lptr)[1], "), `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ").");
    if (dims(gval)[1] != NZ) reject("brm_gmrf_logdensity: dim mismatch — `gval` dim 1 (= ", dims(gval)[1], ") does not match `NZ` (= ", NZ, "), inferred from `grow` dim 1. `NZ` sizes: `grow` dim 1 (= ", dims(grow)[1], "), `gval` dim 1 (= ", dims(gval)[1], ").");
    if (dims(previous_pos)[1] != ND) reject("brm_gmrf_logdensity: dim mismatch — `previous_pos` dim 1 (= ", dims(previous_pos)[1], ") does not match `ND` (= ", ND, "), inferred from `previous_col` dim 1. `ND` sizes: `previous_col` dim 1 (= ", dims(previous_col)[1], "), `previous_pos` dim 1 (= ", dims(previous_pos)[1], ").");
    vector[(dims(mass)[1] + dims(lrow)[1])] factor = brm_gmrf_factor(
        (1.0 / spatial_length),
        (spatial_length / 2.0),
        mass,
        gptr,
        grow,
        gval,
        lptr,
        lrow,
        previous_ptr,
        previous_col,
        previous_pos
    );
    real logdet_space = (((2.0 * sum(log(segment(factor, 1, N)))) - sum(log(mass))) - (N * log((2.0 * 3.141592653589793))));
    real lp = (((T * C * logdet_space) / 2.0) - ((D * log((2.0 * 3.141592653589793))) / 2.0));
    for(c in 1:C) {
        lp -= (N * T * log(L[c, c]));
    }
    matrix[N, C] residual;
    for(t in 1:T) {
        real a = ((t == 1) ? 0.0 : exp(((-(times[t] - times[(t - 1)])) / temporal_length)));
        real variance = ((t == 1) ? 1.0 : (-expm1(((-2.0 * (times[t] - times[(t - 1)])) / temporal_length))));
        for(c in 1:C) {
            for(i in 1:N) {
                int index = (permutation[i] + (N * ((c - 1) + (C * (t - 1)))));
                real z = field[index];
                if((t > 1)) {
                    z -= (a * field[(index - (N * C))]);
                }
                for(k in 1:(c - 1)) {
                    z -= (residual[i, k] * L[c, k]);
                }
                residual[i, c] = (z / L[c, c]);
            }
        }
        real quadratic = 0.0;
        for(c in 1:C) {
            for(i in 1:N) {
                real stiffness = 0.0;
                for(p in gptr[i]:(gptr[(i + 1)] - 1)) {
                    stiffness += (gval[p] * residual[grow[p], c]);
                }
                real z = ((mass[i] * (residual[i, c] / spatial_length)) + ((spatial_length / 2.0) * stiffness));
                quadratic += square((z / (sqrt((4.0 * 3.141592653589793 * mass[i])) * sqrt(variance))));
            }
        }
        lp -= (quadratic + ((N * C * log(variance)) / 2.0));
    }
    return lp;
}
vector brm_gmrf_factor(
    real mass_scale,
    real stiffness_scale,
    vector mass,
    array[] int gptr,
    array[] int grow,
    vector gval,
    array[] int lptr,
    array[] int lrow,
    array[] int previous_ptr,
    array[] int previous_col,
    array[] int previous_pos
) {
    int N = dims(mass)[1];
    int NP = dims(gptr)[1];
    int NZ = dims(grow)[1];
    int NL = dims(lrow)[1];
    int ND = dims(previous_col)[1];
    if (dims(lptr)[1] != NP) reject("brm_gmrf_factor: dim mismatch — `lptr` dim 1 (= ", dims(lptr)[1], ") does not match `NP` (= ", NP, "), inferred from `gptr` dim 1. `NP` sizes: `gptr` dim 1 (= ", dims(gptr)[1], "), `lptr` dim 1 (= ", dims(lptr)[1], "), `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ").");
    if (dims(previous_ptr)[1] != NP) reject("brm_gmrf_factor: dim mismatch — `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ") does not match `NP` (= ", NP, "), inferred from `gptr` dim 1. `NP` sizes: `gptr` dim 1 (= ", dims(gptr)[1], "), `lptr` dim 1 (= ", dims(lptr)[1], "), `previous_ptr` dim 1 (= ", dims(previous_ptr)[1], ").");
    if (dims(gval)[1] != NZ) reject("brm_gmrf_factor: dim mismatch — `gval` dim 1 (= ", dims(gval)[1], ") does not match `NZ` (= ", NZ, "), inferred from `grow` dim 1. `NZ` sizes: `grow` dim 1 (= ", dims(grow)[1], "), `gval` dim 1 (= ", dims(gval)[1], ").");
    if (dims(previous_pos)[1] != ND) reject("brm_gmrf_factor: dim mismatch — `previous_pos` dim 1 (= ", dims(previous_pos)[1], ") does not match `ND` (= ", ND, "), inferred from `previous_col` dim 1. `ND` sizes: `previous_col` dim 1 (= ", dims(previous_col)[1], "), `previous_pos` dim 1 (= ", dims(previous_pos)[1], ").");
    vector[NL] ldl_values = rep_vector(0.0, NL);
    vector[N] diagonal = rep_vector(0.0, N);
    vector[N] work = rep_vector(0.0, N);
    for(j in 1:N) {
        for(p in lptr[j]:(lptr[(j + 1)] - 1)) {
            work[lrow[p]] = 0.0;
        }
        for(p in gptr[j]:(gptr[(j + 1)] - 1)) {
            if((grow[p] >= j)) {
                work[grow[p]] = (stiffness_scale * gval[p]);
            }
        }
        work[j] += (mass_scale * mass[j]);
        for(q in previous_ptr[j]:(previous_ptr[(j + 1)] - 1)) {
            int k = previous_col[q];
            int start = previous_pos[q];
            real v = (ldl_values[start] * diagonal[k]);
            for(p in start:(lptr[(k + 1)] - 1)) {
                work[lrow[p]] -= (ldl_values[p] * v);
            }
        }
        diagonal[j] = work[j];
        ldl_values[lptr[j]] = 1.0;
        for(p in (lptr[j] + 1):(lptr[(j + 1)] - 1)) {
            ldl_values[p] = (work[lrow[p]] / diagonal[j]);
        }
    }
    return append_row(diagonal, ldl_values);
}

The StanBlocks and Stan panes are generated from this declaration during the documentation build. Construct SBBRMI(small_field) to prepare the same model. The field is a direct predictor contribution: its amplitude is the addressed sd, without a second population coefficient multiplying it. Add an intercept explicitly with 1 + gmrf(...) when the model needs one.

Omit channel for a single field. With a channel column, omitting cor gives independent channels conditional on their shared field hyperparameters. cor=Omega accepts either a known correlation matrix in the data or an Omega ~ LKJCholesky(K, eta) declaration. Its dimension must match the fitted channel count. A matrix supplied as data contains correlations; a sampled LKJCholesky declaration supplies their lower Cholesky factor.

The three term parameters are positive and default to LogNormal(0, 1):

Replace ~ Prior(...) by = value to hold one of these parameters fixed. The spatial and temporal components must be addressed explicitly. The two coordinate axes use one isotropic spatial length; this term does not infer separate east–west and north–south length scales.

Covariance and length convention ​

The spatial Matérn smoothness is ν=1. BRM uses

κ=2ℓs,ρ=8κ=2ℓs,

where ρ is the conventional practical range. Thus a prior expressed for ρ must be converted to one on ℓs=ρ/2. For example, log⁡ρ∼N(m,s2) corresponds to log⁡ℓs∼N(m−log⁡2,s2). The time length is already the OU correlation time: a gap of ℓt has correlation e−1.

In the infinite-domain continuum, the covariance between positions a distance r apart, time gap d apart and channels c,c′ is

σ2Ωcc′(κr)K1(κr)exp⁡(−|d|/ℓt),

with the spatial factor defined as one at r=0. K1 is the modified Bessel function of the second kind. The finite mesh approximates this spatial covariance; its boundary and resolution affect both variances and correlations.

For the linear triangular finite elements, let C be the diagonal lumped mass matrix and G the stiffness matrix. The standardized spatial precision used by the implementation is

K=κ2C+G,Qs=KC−1K4πκ2.

The mesh uses natural Neumann boundary conditions. Consequently, σ is a nominal continuum SD, not a guarantee of exactly that marginal SD at every finite-mesh vertex or interpolated observation. Check interior and boundary covariance over the spatial range prior, refine the mesh where needed, and extend it beyond the observation hull. BRM does not silently truncate the range prior to fit the mesh or renormalize each vertex separately.

For fitted times t1<⋯<tT, the standardized vertex-by-channel field Ft evolves as

vec(F1)∼N(0,Ω⊗Qs−1),Ft=atFt−1+1−at2Et,at=exp⁡(−(tt−tt−1)/ℓt),vec(Et)∼iidN(0,Ω⊗Qs−1).

This includes the stationary initial distribution and exact OU transitions over irregular gaps. For barycentric weights wij, observation i reads σ∑j=13wijFti[vij,ci]. Observations are not aggregated to mesh vertices.

Fitted support and replay ​

The fitted state contains every mesh vertex at every fitted channel and sorted distinct observed time. Vertex order comes from the supplied mesh; channel and time labels identify the other axes. Rows may share time and channel values, and their input order does not determine latent coordinates. An observation outside the supplied triangulation is rejected.

reprocess(sb, new_rows) preserves the fitted mesh, time lattice, channel axis and priors by default. New observation coordinates inside the mesh may change the three vertex reads. Reordered rows and subsets of fitted times or channels retain the same latent field. A previously unseen time or channel requires rebuilding the model; frozen replay does not append states or interpolate in time.

Cost of the representation ​

With N vertices, Ch channels and T fitted times, there are NChT latent field coordinates. Sparse spatial precision and local observation reads reduce the cost of working with the prior, but do not remove this state dimension. The joint prior uses spatial factors and OU transitions without constructing a dense space-time covariance. When this state is far larger than the reads, use neighbors= below.

Posterior inference must also account for the observation model and shared parameters. Sparse posterior factorization can have substantial fill, and a fast precision application alone does not establish scalable marginalization. The Embedded Laplace section below reports what its operator algebra measures at large sizes.

A field too large for a mesh: neighbors= ​

Replace mesh by neighbors=m when the mesh × time state is too large and the rows read far fewer position and time pairs than that product:

julia
field ~ 0 + gmrf((east, north), time, channel; neighbors=20, cor=Omega)

The field has the same three parameters, addresses, priors and length convention. Its latent state is one coordinate per channel at each distinct (east, north, time) the rows read, so it is bounded by the data rather than by vertices × times. A row reads its own state directly.

Instead of a finite-element precision, the joint law is a product of Gaussian conditionals under the exact covariance of the section above, the continuum (κr)K1(κr)exp⁡(−|d|/ℓt):

xi∣xN(i)∼N(biTxN(i),Fi),bi=KN(i)N(i)−1KN(i)i,Fi=1−KiN(i)bi.

Its precision (I−B)TF−1(I−B) is sparse. Reads are ordered by time, then by one greedy maximin position order for the whole support. The conditioning set N(i) of a read holds:

  • its m nearest lower-order positions read at its own time;

  • the previous read of its own position and of each of those neighbours;

  • when its own position was not read at the previous read time, its m nearest among the latest earlier reads, reaching back until they hold at least m.

Selection depends only on the coordinates and m, never on the sampled lengths. Only bi and Fi move with them, and reads with the same geometry share one solve, so a repeated observing pattern costs one solve per position and gap rather than one per read.

What it preserves. The spatial correlation is the continuum Matérn at the actual positions: there is no mesh boundary inflation, no resolution floor at short ranges and no interpolation within triangles. Channels are exactly separable (Ω⊗K). On positions read at the same times, the implied covariance is the spatial approximation times the exact OU correlation across every gap. No time gap is cut: every read time conditions on earlier reads however long ago they were.

What it approximates. The conditioning set. Implied covariances differ from the exact covariance by an error that shrinks with m, is largest at distances near the range when the range is much longer than the read spacing, and grows for pairs linked only through a chain of sparsely read times. Measure it for your support and your range prior: on a network of about 1,600 positions, a range about five times the typical spacing has a largest covariance error of about 0.04 at m=20 and 0.015 at m=30. A conditioning set holds at most 2m+1 reads when its position was read at the previous read time, and 3m+1 otherwise.

Lengths far beyond the read domain make a conditional correlation numerically singular, which raises a DomainError naming them. Positions a metre apart in a domain of about 1,000 km first fail at a range of about 5,000 km with a correlation time of 105 time units, or a range of 106 km at any correlation time.

Frozen replay reads only fitted (position, time) pairs, in any order and any subset. A new position or time needs a conditional prediction law and is refused. It is one model-scope field: use mesh= for independent fields in plate cells. Embedded Laplace does not integrate it.

Independent fields in plate cells ​

Write the term inside @plate for p in groups(g) to give each cell its own field. Every cell keeps the shared mesh but fits its own times and channels from its rows, and its term hyperparameters are its own:

julia
@plate for p in groups(window)
    field ~ 0 + gmrf((east[p], north[p]), time[p], channel[p];
        mesh=(vertices=xy, cells=triangles), cor=Omega)
    sd(field, gmrf((east[p], north[p]), time[p], channel[p])) ~ Exponential(0.7)
    y[p] ~ Normal(field, 0.2)
end

A prior may read a model-scope parameter or a cell-local one declared in the same cell (tau ~ Exponential(s), then sd(...) ~ Exponential(tau)). A cell declaration never takes caller data of the same name: on SBBRMI it is emitted as a StanBlocks local binding. Cells are independent conditional on the shared hyperparameters; use one model-scope field when cells must be correlated. On the ReactiveKernels backend the cell formula must be 0 + gmrf(...) alone, a correlation declared inside the cell is not lowered, and replay keeps the fit's cells.

Embedded Laplace ​

On RKBRMI, brm_laplace_problem(rk; ad_backend, integrate=(declaration,)) integrates a model-scope field, where declaration is the field's RK declaration (gmrf_<predictor>_<axes…>, as brm_laplace_plan lists it), and brm_laplace_plan(rk; ad_backend, integrate=:auto) admits recognized affine Normal rows, or eligible count rows that pass the local ESS gate. From BRM 0.2.166, arbitrary plate cells and model-value observations require explicit selection: automatic planning cannot certify their conditional log-concavity. Concavity does not itself guarantee Gaussian approximation accuracy. With affine Normal rows and exact algebra the integrated target is the exact marginal. The field's precision moves with its lengths and channel factor, and the target's gradient includes their log-determinant terms. brm_laplace_problem(rk; ad_backend, integrate=plan) applies the plan to the same target, and deepcopy gives each chain its own problem. integrate=(declaration,) also integrates one field per @plate for p in groups(g) cell, each cell's rows reading only that cell's field. Applying an explicitly selected plan and deepcopy also work for these fields. Automatic selection retains the structural eligibility rule above; a passing local diagnostic does not admit a cell.

Above 1,024 coordinates solver=:auto uses operator algebra, which needs no space-time factorization. Its determinant is an estimate from fixed probes, so even with Normal rows the target is then approximate. A component holding one field uses a reference with one sparse spatial factor per channel and time, which sees the data's curvature and stays fixed. The estimate is the difference from that reference rebuilt at each point, whose own determinant is exact, and the gradient is the exact derivative of the fixed-probe value. Fields read by the same rows are coupled through one of them. Measured per warm value and gradient, one CPU of a loaded host, one Normal field at its prior medians:
