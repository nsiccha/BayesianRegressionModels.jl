Response families ​

Specify the sampling distribution beside each response and use formulas for any of its parameters. Links are explicit: log(sigma) ~ 1 + x declares a positive scale, while sigma ~ 1 + x declares an unconstrained predictor.

Support and parameters ​

Choose support first, then a parameterization whose priors you can interpret. The terms reference lists every mapped constructor and the supported compositions.

Julia's Exponential and Gamma arguments are scales. BRM converts them to Stan's rate convention when emitting Stan. NormalCanon(eta, lambda) uses precision, NegativeBinomial2(mu, phi) has variance mu + mu^2 / phi, and the scale in a Student-t model is not its standard deviation.

This model uses one covariate in a real-valued measurement and a positive waiting time. Each response has its own distributional predictors.

brm-comparison
Real and positive responses
julia
model = (@brm begin
    mu ~ 1 + x
    log(sigma) ~ 1
    log(wait_mean) ~ 1 + x
    y ~ Normal(mu, sigma)
    waiting ~ InverseGaussian(wait_mean, concentration)

    effect(mu, :) ~ Normal(0, 1)
    effect(sigma, Intercept) ~ Normal(-1, 0.5)
    effect(wait_mean, :) ~ Normal(0, 0.5)
    concentration ~ Exponential(1)
end)((; x=[-1., 0., 1.], y=[-0.2, 0.4, 0.8], waiting=[0.5, 0.9, 1.8]))

begin
    X_mu = hcat(rep_vector(1.0, num_elements(x)), x)
    pop_mu ~ _popefs_normal_coefs(; X = X_mu, beta_loc = [0, 0], beta_scale = [1, 1])
    X_log_sigma = hcat(rep_vector(1.0, num_elements(y)))
    pop_log_sigma ~ _popefs_normal(; X = X_log_sigma, beta_loc = [-1], beta_scale = [0.5])
    log_sigma = pop_log_sigma
    sigma = exp(log_sigma)
    X_log_wait_mean = hcat(rep_vector(1.0, num_elements(x)), x)
    pop_log_wait_mean ~ _popefs_normal(; X = X_log_wait_mean, beta_loc = [0, 0], beta_scale = [0.5, 0.5])
    log_wait_mean = pop_log_wait_mean
    wait_mean = exp(log_wait_mean)
    y ~ normal_id_glm(X_mu, 0.0, pop_mu, sigma)
    mu = X_mu * pop_mu
    concentration ~ exponential(1.0 ./ 1)
    waiting ~ brm_inverse_gaussian(wait_mean, concentration)

real brm_inverse_gaussian_lpdf(
    real y,
    real mu,
    real lambda
) {
    if((mu <= 0.0)) {
        return negative_infinity();
    } else {
        if((lambda <= 0.0)) {
            return negative_infinity();
        } else {
            if((y <= 0.0)) {
                return negative_infinity();
            } else {
                return (
                    (
                        (log(lambda) - (1.8378770664093456 + (3.0 * log(y)))) -
                        ((lambda * (y - mu) * (y - mu)) / (mu * mu * y))
                    ) /
                    2.0
                );
            }
        }
    }
}

real brm_inverse_gaussian_rng(
    real mu,
    real lambda
) {
    if((mu <= 0.0)) {
        reject("brm_inverse_gaussian_rng: mu must be strictly positive");
        return 0.0;
    } else {
        if((lambda <= 0.0)) {
            reject("brm_inverse_gaussian_rng: lambda must be strictly positive");
            return 0.0;
        } else {
            real z = normal_rng(0.0, 1.0);
            real v = (z * z);
            real w = (mu * v);
            real x = (mu + ((mu / (2.0 * lambda)) * (w - sqrt((w * ((4.0 * lambda) + w))))));
            real u = uniform_rng(0.0, 1.0);
            if((u < (mu / (mu + x)))) {
                return x;
            } else {
                return ((mu * mu) / x);
            }
        }
    }
}

Counts and extra zeros ​

HurdlePoisson(lambda, p_zero) assigns probability p_zero to zero and uses a zero-truncated Poisson for positive counts. With ZeroInflatedPoisson(lambda, zi), the ordinary Poisson component can also produce zeros. These probabilities therefore have different meanings.

brm-comparison
Hurdle counts and trial outcomes
julia
model = (@brm begin
    log(lambda) ~ 1 + x
    logit(p_zero) ~ 1
    eta ~ 1 + x
    count ~ HurdlePoisson(lambda, p_zero)
    successes ~ BinomialLogit(trials, eta)

    effect(lambda, :) ~ Normal(0, 0.5)
    effect(p_zero, Intercept) ~ Normal(0, 1)
    effect(eta, :) ~ Normal(0, 1)
end)((; x=[-1., 0., 1., 2.], count=[0, 1, 0, 4],
    trials=[10, 10, 12, 12], successes=[2, 5, 8, 10]))

Categories and thresholds ​

A nested formula gives CategoricalLogit one predictor per non-reference level. Plain vectors use sorted unique levels; a categorical vector uses its declared level order. The first level has logit zero. Fitted levels remain fixed during replay.

An ordinal model supplies its location through thresholds, so its common predictor has no intercept. Cumulative() has ordered thresholds; StoppingRatio() has separate stage intercepts. Both accept LogitLink(), ProbitLink() or CloglogLink().

    matrix[(2 + 1), x_n] choice_categorical_logits = (hcat(rep_vector(0.0, num_elements(choice)), choice_nested_arg1_class2, choice_nested_arg1_class3)');
    vector[x_n] pop_eta = (X_eta * pop_eta_beta_pop);
    vector[x_n] eta = pop_eta;
}
model {
    pop_choice_nested_arg1_class2_beta_pop ~ std_normal();
    pop_choice_nested_arg1_class3_beta_pop ~ std_normal();
    choice ~ categorical_logit(choice_categorical_logits);
    pop_eta_beta_pop ~ normal([0]', [1]');
    rating_thresholds ~ std_normal();
    rating ~ brm_ordinal(eta, rating_thresholds, 1.0, 1, 2, rating_threshold_effect);
}
generated quantities {
    vector[x_n] choice_likelihood = categorical_logit_lpmfs(choice, choice_categorical_logits);
    array[x_n] int choice_gen = categorical_logit_int_rng(choice_n, choice_categorical_logits);
    vector[num_elements(rating)] rating_likelihood = brm_ordinal_lpmfs(rating, eta, rating_thresholds, 1.0, 1, 2, rating_threshold_effect);
    array[num_elements(rating)] int rating_gen = brm_ordinal_int_rng(rating_n, eta, rating_thresholds, 1.0, 1, 2, rating_threshold_effect);
}

Observation mechanisms ​

Truncation conditions on being inside a sampling interval. Censoring records a limit in place of an unobserved value. An interval-censored response is the lower endpoint, and the likelihood is the probability of the interval (response, upper]. These are different observations of the same base law.

Selected positive valuesy ~ truncated(Normal(mu, sigma); lower=0)Truncated values
Detection limity ~ censored(Normal(mu, sigma); lower=lloq)Values with the same clamping
Known intervaly ~ interval_censored(Normal(mu, sigma); upper=hi)Uncoarsened values from the base law
Partly missing continuous valuesmi(y) ~ Normal(mu, sigma)A latent value for each missing row
Known relative precisiony ~ weighted(Normal(mu, sigma), aweights(w))Normal SD sigma / sqrt(w)
Replicated or powered densityy ~ weighted(Normal(mu, sigma), fweights(w))Base-law prediction; density multiplied by the weight

The reference identifies supported base families. Response bounds may be data columns. interval_censored(x; upper=lloq) inside a predictor has a separate meaning: it imputes a censored covariate.

Mixtures and correlated outcomes ​

MixtureModel([Normal(mu1, sigma1), Normal(mu2, sigma2)], share) marginalizes component membership. Weights may be fixed, a declared Dirichlet simplex, or a valid row-dependent expression. The reference describes allowed component families. Stan can return membership probabilities as well as predictive draws; RK currently supplies the density, gradient and pointwise likelihood for this surface, but not mixture prediction.

For residual correlation, declare L ~ LKJCovarianceFactor(2; scale_prior=Exponential(1), shape=2) and observe [y1, y2] ~ MvNormalCholesky([mu1, mu2], L). This is a joint Gaussian observation per complete row. Non-Gaussian residual copulas and partially missing response vectors are outside that surface.
