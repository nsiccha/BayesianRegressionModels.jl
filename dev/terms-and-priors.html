Terms and priors ​

Choose a predictor term, attach a prior to the quantity it creates, and inspect the resulting declaration before fitting. A term may allocate a coefficient, a group-effect block or a latent function; these have different prior addresses.

Prior targets ​

The three forms below name an authored parameter, a formula coefficient, or a quantity owned by a term or group block. Distribution arguments use Julia's conventions: Exponential and Gamma take a scale, not Stan's rate.

TargetPrior statementQuantity
Authored parametersigma ~ Exponential(1)A positive scalar
Formula coefficienteffect(mu, x) ~ Normal(0, 0.3)The coefficient multiplying x
Term or group parametersd(mu, subject) ~ Exponential(0.5)The subject-effect SD

Population coefficients default to independent standard normals. A smooth's amplitude belongs to the smooth, so use sd(mu, hsgp(x)); it has no additional population multiplier. offset(x) fixes the multiplier at one and allocates no coefficient. The terms reference lists defaults, prior families and backend coverage by term.

This model overrides the population slope, the group SD and the HSGP amplitude. It retains the HSGP's approximation-validity bound on its length scale.

functions {
matrix hcat(
    vector x,
    vector y
) {
    int n = dims(x)[1];
    if (dims(y)[1] != n) reject("hcat: dim mismatch — `y` dim 1 (= ", dims(y)[1], ") does not match `n` (= ", n, "), inferred from `x` dim 1. `n` sizes: `x` dim 1 (= ", dims(x)[1], "), `y` dim 1 (= ", dims(y)[1], ").");
    return append_col(x, y);
}
vector brm_hsgp_sqrt_spd(
    matrix omega2,
    real sigma,
    vector rho
) {
    int m = dims(omega2)[1];
    int d = dims(omega2)[2];
    if (dims(rho)[1] != d) reject("brm_hsgp_sqrt_spd: dim mismatch — `rho` dim 1 (= ", dims(rho)[1], ") does not match `d` (= ", d, "), inferred from `omega2` dim 2. `d` sizes: `omega2` dim 2 (= ", dims(omega2)[2], "), `rho` dim 1 (= ", dims(rho)[1], ").");
    vector[m] rv;
    real scale = sigma;
    for(axis in 1:d) {
        scale *= sqrt((rho[axis] * 2.5066282746310002));
    }
    for(b in 1:m) {
        real exponent = 0.0;
        for(axis in 1:d) {
            exponent += (rho[axis] * rho[axis] * omega2[b, axis]);
        }
        rv[b] = (scale * exp((-0.25 * exponent)));
    }
    return rv;
}

A colon supplies a default for every matching predictor or coefficient; the more specific address wins. Equal-specificity ties and unmatched addresses raise errors during lowering. optional(address) ~ prior is for a reusable prior block whose target may be absent in some members of a model family.

A linked formula such as log(sigma) ~ 1 + x takes addresses under sigma, with coefficient priors on the log scale. A categorical column uses its column name, effect(mu, site). Cell means also accept site_lvl_k for the level in fitted-order position k. For a shared |p| group block, sd(:, p) reaches all margins and cor(:, p) sets its LKJ prior; sd(mu, p) selects the margins belonging to mu. The LKJ dimension must match the block width.

Term addresses omit numeric and keyword arguments: address me(x, 0.3) as me(x). A tensor smooth also needs its penalty component, for example sd(mu, t2(x, z), rr). Standardized innovations retain their standard-normal law; changing their scale would duplicate the term's amplitude.

Bounds and vectors ​

restricted(D; lower, upper) evaluates the original density on the bounded support. truncated(D; lower, upper) also divides by the probability mass inside the bounds. They give the same posterior when that mass is constant; with sampled hyperparameters, their joint laws differ.

The vector statement here declares one independent positive scale per observation.

real lower_conditioning_normal_lpdf(
    real y,
    real lo,
    real args1,
    real args2
) {
    array[1] real rv;
    rv[1] = negative_infinity();
    if((y >= lo)) {
        rv[1] = (normal_lpdf(y | args1, args2) - normal_lccdf_stable(lo, args1, args2));
    }
    return rv[1];
}
real normal_lccdf_stable(
    real x,
    real loc,
    real scale
) {
    return (is_inf(x) ? ((x > 0) ? negative_infinity() : 0.0) : ((((x - loc) / scale) > 35) ? std_normal_lcdf_tail(((loc - x) / scale)) : ((((x - loc) / scale) >= 0) ? (log(erfc(((x - loc) / (scale * sqrt(2.0))))) - log(2.0)) : log1m((0.5 * erfc(((-(x - loc)) / (scale * sqrt(2.0)))))))));
}
real std_normal_lcdf_tail(
    real z
) {
    return ((-0.5 * square(z)) + std_normal_scaled_lcdf_tail(z));
}
real std_normal_scaled_lcdf_tail(
    real z
) {
    real w = inv(square(z));
    return (
        ((-log((-z))) - 0.9189385332046728) +
        log1p((w * (-1 + (w * (3 + (w * (-15 + (w * (105 + (w * (-945 + (w * 10395))))))))))))
    );
}

The length of a declared vector comes from an integer or data expression. An undeclared x ~ Normal(0, scales) with vector data has omitted-response semantics; it is not a vector-parameter declaration. mo(c) returns a monotonic effect on observation rows, so it is not a substitute for a standalone simplex.

Structured shrinkage ​

effect(mu, :) ~ r2d2(R2=Beta(1, 1), tau_bsv=0.5) allocates a predictor's variance between its non-intercept coefficients and one random-intercept residual. sd(:, p) ~ r2d2(reference_scale=sigma) instead allocates a shared group block's variance; include=(:population, :contrasts) extends that budget to its predictors' coefficients. The reference documents exclusions and reference-scale choices. These constructions replace independent priors; they are not extra priors on top of them.

beta ~ Horseshoe(...) declares a coefficient used through an assignment such as mu = beta * x. effect(mu, x) ~ Horseshoe(...) addresses an existing population coefficient. Inspect the backend's supported form before sharing a shrinkage scale across coefficients.

For a fitted application of group and scale priors, continue to the Warfarin example.
