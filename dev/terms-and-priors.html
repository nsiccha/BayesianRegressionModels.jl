Terms and priors ​

Choose a predictor term, attach a prior to the quantity it creates, and inspect the resulting declaration before fitting. A term may allocate a coefficient, a group-effect block or a latent function; these have different prior addresses.

Prior targets ​

The three forms below name an authored parameter, a formula coefficient, or a quantity owned by a term or group block. Distribution arguments use Julia's conventions: Exponential and Gamma take a scale, not Stan's rate.

TargetPrior statementQuantity
Authored parametersigma ~ Exponential(1)A positive scalar
Formula coefficienteffect(mu, x) ~ Normal(0, 0.3)The coefficient multiplying x
Term or group parametersd(mu, subject) ~ Exponential(0.5)The subject-effect SD

Population coefficients default to independent standard normals. A smooth's amplitude belongs to the smooth, so use sd(mu, hsgp(x)); it has no additional population multiplier. offset(x) fixes the multiplier at one and allocates no coefficient. The terms reference lists defaults, prior families and backend coverage by term.

This model overrides the population slope, the group SD and the HSGP amplitude. It retains the HSGP's approximation-validity bound on its length scale.

"""
Group-level (varying) effects of grouping `g`.

Non-centered, from the scale `tau[1]` (drawn from its prior) and standardized effects
`z[1:length(levels(g)), 1:1] ~ Normal(0, 1)`. Returns the
level-by-margin matrix `z .* tau[1]`, one row per level of `g` in order.
"""
brm_group_effects(g) = begin
        tau[1:1] .~ Exponential.(0.5)
        z[1:length(levels(g)), 1:1] .~ Normal.(0, 1)
        return z .* tau[1]
    end

"""
The fitted interval of an HSGP term's basis, from its training (fit-role) axes.

Returns one vector `fit`: each axis's center and half-width. The basis and
length-scale floor graphs read it, so a prediction uses the training interval.
"""
ReactiveKernels.@kernel(brm_hsgp_fit_graph(axis_fit, settings) = begin
            center = sum(axis_fit) / length(axis_fit)
            width = settings[1] * maximum(abs.(axis_fit .- center))
            fit = [center, width]
            return fit
        end)

"""
The smallest length scale an HSGP term's basis resolves, per axis.

For `m` basis functions on an axis of half-width `L` the floor is
`(4L / pi) * sqrt(log(threshold) / (m^2 - 1))` (`0.0` for one function), below
which the omitted frequencies would carry too much weight.
"""
ReactiveKernels.@kernel(brm_hsgp_rho_floor_graph(fit, modes) = begin
            width = fit[2]
            rho_floor = if modes[1] == 1
                    0.0
                else
                    ((4width) / pi) * sqrt(log(100.0) / (modes[1] ^ 2 - 1))
                end
            return rho_floor
        end)

"""
The Hilbert-space basis of an HSGP term at the rows.

Returns `(PHI, omega2)`: `PHI` holds one column per basis function, the Laplacian
eigenfunctions on the term's interval evaluated at each row's axes, and `omega2`
the matching squared frequencies, which the spectral density reads.
"""
ReactiveKernels.@kernel(brm_hsgp_basis_graph(axis, fit, modes) = begin
            B = prod(modes)
            center = fit[1]
            width = fit[2]
            omega2 = ReactiveKernels.plate(1:B) do mode
                    return ((mode * pi) / (2width)) ^ 2
                end
            basis_rows = ReactiveKernels.plate(axis) do x
                    values = ReactiveKernels.plate(1:B) do b
                            return sin(sqrt(omega2[b]) * ((x - center) + width)) / sqrt(width)
                        end
                    return values
                end
            PHI = stack(basis_rows; dims = 1)
            return (PHI, omega2)
        end)

"""
The weight of each HSGP basis function: the square root of the covariance's
spectral density at its frequency, for the marginal scale `sigma` and length
scale `rho`.
"""
ReactiveKernels.@kernel(brm_hsgp_spectral_scales(axis, fit, modes, sigma, rho) = begin
            (PHI, omega2) = brm_hsgp_basis_graph(axis, fit, modes)
            weights = ReactiveKernels.plate(axes(omega2, 1)) do b
                    return (sigma * (rho * sqrt(2pi)) ^ (1 / 2)) * exp(-0.25 * (rho ^ 2 * omega2[b]))
                end
            return weights
        end)

"""
An HSGP term's value at each row: the basis `PHI` times the basis weights `scales`
times the standardized coefficients `z`, `PHI * (scales .* z)`.
"""
ReactiveKernels.@kernel(brm_hsgp_spectral_graph(axis, fit, modes, scales, z) = begin
            (PHI, omega2) = brm_hsgp_basis_graph(axis, fit, modes)
            value = PHI * (scales .* z)
            return value
        end)

"""
A Hilbert-space Gaussian-process (HSGP) effect.

Draws the length scale `rho_iso`, each truncated below at the floor `rho_floor` the basis resolves, the marginal scale `sigma` and standardized basis
coefficients `beta_raw ~ Normal(0, 1)`. Each basis function is weighted by the
square root of the covariance's spectral density (`spectral_scale`), and the
effect at the rows is the basis times the weighted coefficients.
"""
brm_hsgp_effect(axis, fit, modes, rho_floor) = begin
        rho_iso ~ restricted(LogNormal(0.0, 1.0), rho_floor, Inf)
        sigma ~ Exponential(0.7)
        beta_raw[1:prod(modes)] .~ Normal.(0, 1)
        spectral_scale = brm_hsgp_spectral_scales(axis, fit, modes, sigma, rho_iso)
        return brm_hsgp_spectral_graph(axis, fit, modes, spectral_scale, beta_raw)
    end

"""
Population-level effects: one coefficient per column of the design matrix `X`.

Draws `beta_pop[1:ncoef] ~ Normal(loc, scale)` and returns the linear predictor
`X * beta_pop`. `ncoef` is the number of columns of `X`. Each prior argument (`loc`, `scale`) is one value for all coefficients or a vector with one per coefficient.
"""
brm_population_effects(X, ncoef, loc, scale) = begin
        beta_pop[1:ncoef] .~ Normal.(loc, scale)
        return X * beta_pop
    end

vector brm_hsgp_sqrt_spd(
    matrix omega2,
    real sigma,
    vector rho
) {
    int m = dims(omega2)[1];
    int d = dims(omega2)[2];
    if (dims(rho)[1] != d) reject("brm_hsgp_sqrt_spd: dim mismatch — `rho` dim 1 (= ", dims(rho)[1], ") does not match `d` (= ", d, "), inferred from `omega2` dim 2. `d` sizes: `omega2` dim 2 (= ", dims(omega2)[2], "), `rho` dim 1 (= ", dims(rho)[1], ").");

    real scale = sigma;
    for(axis in 1:d) {
        scale *= sqrt((rho[axis] * 2.5066282746310002));

            exponent += (rho[axis] * rho[axis] * omega2[b, axis]);
        }
        rv[b] = (scale * exp((-0.25 * exponent)));
    }
    return rv;

Structured shrinkage ​

effect(mu, :) ~ r2d2(R2=Beta(1, 1), tau_bsv=0.5) allocates a predictor's variance between its non-intercept coefficients and one random-intercept residual. sd(:, p) ~ r2d2(reference_scale=sigma) instead allocates a shared group block's variance; include=(:population, :contrasts) extends that budget to its predictors' coefficients. The reference documents exclusions and reference-scale choices. These constructions replace independent priors; they are not extra priors on top of them.

beta ~ Horseshoe(...) declares a coefficient used through an assignment such as mu = beta * x. effect(mu, x) ~ Horseshoe(...) addresses an existing population coefficient. Inspect the backend's supported form before sharing a shrinkage scale across coefficients.
